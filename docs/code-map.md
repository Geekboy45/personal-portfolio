# Code map

## Current state

A bilingual personal portfolio is implemented. The former Pokémon reference modules remain in source only, with no public route. Exact versions and scripts are owned by [package.json](../package.json); see [README](../README.md) for startup and replacement instructions.

- Installed Next.js baseline: **16.4.2**. Explicit server/static scripts use traditional caching; derived projects select one profile.
- The portfolio is prerendered in English at `/` and Spanish at `/es/`; the original Pokémon modules are not composed into public routes. No auth, database or telemetry exporter exists. GitHub Pages publishes the static artifact through Actions.
- Accepted constraints and deferred choices are owned by [AGENTS.md](../AGENTS.md) and its linked topic policies.

Per-section animation controls are intentionally absent from the real portfolio. The retired `/explore/` route returns 404; the source reference modules below are not public screens.

## Maintaining this map

Add module entries only when implemented: purpose, primary entry path/symbol, execution boundary, important direct collaborators, and test location or real verification command. Use stable links to actual files.

Update affected entries when structure, contracts, boundaries, or commands change enough to alter navigation. Do not list every symbol, copy policies, or update the map for local changes with no navigation impact. Known-file tasks may start directly from the source and applicable policy.

The [hero CTA arrow](../src/features/portfolio/hero-contact-arrow.client.tsx) is a small preference-aware client island for a native hover/focus transition; the enclosing hero and link remain server-rendered.
